筋トレメニュー管理アプリ

説明:
- 簡易的なフロントエンドアプリです。メニューの追加、編集、削除、完了チェックができます。
- メニューと完了履歴はブラウザの `localStorage` に保存されます。
- 完了チェック時の内容を履歴として記録し、日付を選んで過去の記録を確認できます。
- 1メニュー4セットから始まり、セットごとの重量・回数を追加・入力できます。総負荷（重量×回数）はメニュー別と全体で表示され、完了履歴にも保存されます。休憩時間の入力欄はありません。
- 選択日を終点とした過去30日間の完了種目数を折れ線グラフで表示します。
- JSON のエクスポート／インポートに対応しています。

ファイル:
- `index.html` — メインUI
- `styles.css` — スタイル
- `app.js` — ロジック
- `data_sample.json` — 空のときに読み込まれるサンプルデータ

実行方法:
1. プロジェクトルートで簡易 HTTP サーバを起動します（推奨）。PowerShell で:

```powershell
python -m http.server 8001 --directory "ex_筋トレ"
```

2. ブラウザで `http://localhost:8001` を開いてください。

停止: サーバを起動した端末で `Ctrl+C` を押します。

備考:
- データはローカルに保存されます。別コンピュータで共有する場合はエクスポート→インポートを使用してください。
- 要望があれば、ユーザー認証やサーバサイド保存（DB）への対応、UI 改善を行います。
